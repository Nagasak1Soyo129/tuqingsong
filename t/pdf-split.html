PDF 拆分

把一个 PDF 拆开:可以提取指定几页,也可以每页拆成单独文件。

免费使用 →

不用注册,不用安装,打开就能用。

两种模式,对应两类需求

「提取指定页」适合从一份大文件里挑出你要的部分,比如从 50 页的文档里抽出第 3、7、8 页。合成出来的是一份新 PDF。「每页拆成单独文件」适合把一份合并材料拆散,比如把扫描好的多合一文件拆成一个个单页文件,输出的是一个 ZIP 压缩包。

页码怎么写

支持很宽松的写法:1-3 表示第 1 到第 3 页;1,3,5 表示这三页;1-3,5,8 可以混着写;甚至写成 3-1 也会自动纠正顺序。逗号可以是英文逗号、中文逗号或顿号,区间符号用 - 或 ~ 都行。留空则代表全部页。超范围的页码会被自动忽略。

为什么本地处理对这些文件尤其重要

被拆分的 PDF 往往是合同、报告、证明材料。上传到第三方服务器去拆,等于把完整文件交给了别人。这里全程在浏览器完成。

怎么用

  1. 拖入一个 PDF
  2. 选「提取指定页」并填写页码(如 1-3,5),或选「每页拆成单独 PDF」
  3. 点「开始拆分」
  4. 提取模式下载一个 PDF;每页拆分模式下载一个 ZIP
文件不上传服务器。这个页面对应的功能全部在你的浏览器里完成,文件不会发送到任何服务器, 断网也能用。你可以打开浏览器开发者工具的 Network 面板自己验证。

常见问题

页码写错了会怎样?
超出总页数的页码会被忽略,不会报错。如果最终没有任何有效页码,工具会提示你该 PDF 一共几页。
拆分后画质会变吗?
不会。页面是原样搬运的,不重新编码。
加密 PDF 能拆吗?
不能,工具会明确提示文件可能已加密或损坏。
每页拆成单独文件是什么格式?
输出一个 ZIP 压缩包,里面是每一页单独一个 PDF,文件名形如 xxx_第01页.pdf。
