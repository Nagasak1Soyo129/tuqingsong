什么场景用得上

做网页时想把小图标直接内联进 CSS 或 HTML,省一次请求;在没有图床的环境里传递小图;把图片塞进 JSON 或配置文件里。这些时候 Base64 很方便。

注意体积会变大

Base64 会把二进制数据编码成文本,体积大约膨胀 33%。所以这个方式只适合小图标、小色块这类几十 KB 以内的小图。大图转 Base64 会让文件变得很大,反而拖慢加载。

怎么用

转出来的文本形如 data:image/png;base64,iVBORw0KGgo... ,可以直接作为 img 标签的 src,或者 CSS 里的 background-image。工具支持一键复制,也可以下载成 txt 文件。

什么时候不该用 Base64

Base64 只适合很小的图。如果图片超过几十 KB,转出来的文本会长得离谱 —— 嵌进网页里会让 HTML 文件变得很大,反而拖慢加载,不如直接放一个图片文件让浏览器缓存。判断标准很简单:如果这段 Base64 文本你复制粘贴时都觉得卡,那就说明不该这么做。

常见问题

大图适合转 Base64 吗?
不适合。体积会膨胀约 33%,大图转完文本会非常长,影响网页加载速度。建议只对小图标使用。
支持哪些图片格式?
浏览器能读取的格式都可以,转出来的 Data URL 会带上对应的 MIME 类型。
图片会被上传吗?
不会,全程在浏览器本地完成。
