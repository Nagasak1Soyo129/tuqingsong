# 图轻松 —— 图片压缩/转格式/加水印(变现小项目 MVP)

一个纯前端图片工具站,零服务器成本,可免费部署,用「免费引流 + 会员付费」变现。

## 快速开始

直接双击 `index.html` 就能在浏览器里用,无需安装任何东西。

## 功能

- ✅ 图片压缩(质量滑块,实时显示省了多少)
- ✅ 格式转换(JPG / WebP / PNG)
- ✅ 文字水印(位置可调)
- ✅ 批量处理(会员)
- ✅ 图片 100% 本地处理,不上传服务器

## 上线前要做的 3 件事

1. **部署**(免费):推到 GitHub → 用 [Cloudflare Pages](https://pages.cloudflare.com/) 或 Vercel 一键部署,拿到自己的域名。
2. **接入收款 + 自动发码**:
   - 简单版:用 [爱发卡](https://www.ifaka.com/) 等发卡平台,卖激活码,用户买了手动/自动收码。
   - 进阶版:自己做后端,接微信支付/支付宝回调,支付成功自动写入激活码。
   - 把 `app.js` 里的 `DEMO_CODES` 换成真正的校验逻辑(或删掉演示码)。
3. **推广引流**:小红书/知乎/抖音发「免费图片压缩神器」帖子,把流量导到你的站点。
